# Website Pembelian Produk Wardah
  Website ini merupakan website katalog dan pembelian produk Wardah yang dibuat menggunakan HTML, CSS, dan JavaScript. Website dirancang untuk memberikan pengalaman sederhana kepada pengguna dalam melihat, mencari, dan memilih produk skincare dan makeup Wardah.
  
# Fungsi Website :
  Website ini berfungsi sebagai media untuk menampilkan dan mensimulasikan pembelian produk Wardah secara online.

# Fitur Utama :
1. Menampilkan daftar produk Wardah.
2. Pencarian produk.
3. Filter produk berdasarkan kategori skincare dan makeup.
4. Menambahkan produk ke keranjang.
5. Menambahkan produk ke favorit.
6. Form kontak untuk mengirim pesan.
7. Tampilan responsive untuk desktop dan smartphone.

# Teknologi :
1. HTML
2. CSS
3. JavaScript
4. SweetAlert2
   
# Cara Menjalankan :
1. Download atau clone project.
2. Pastikan semua file HTML, CSS, JavaScript, dan gambar berada dalam folder yang sesuai.
3. Buka file index.html menggunakan browser.
4. Untuk pengalaman lebih baik, jalankan menggunakan Live Server di Visual Studio Code.
